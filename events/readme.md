# 📂 Events — Sự kiện & Webinar

> Luồng 2: Events (Acquire new user + Quảng bá hình ảnh)

Mỗi sự kiện = 1 folder con với format `EVENT-XXX_TenEvent/`.

## Cấu trúc mỗi Event

```
EVENT-XXX_TenEvent/
├── brief.md      ← Kế hoạch: topic, speaker, target audience, logistics
├── assets/       ← Hình ảnh, video, slides dùng trong event
└── recap.md      ← Tóm tắt sau event: kết quả, feedback, lessons learned
```
