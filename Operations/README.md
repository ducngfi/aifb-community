# 📂 Operations — Vận hành Nội bộ

> Biên bản họp, ghi chú brainstorming, và tài liệu vận hành chung.

## Cấu trúc

| Thư mục          | Mô tả               |
| ---------------- | ------------------- |
| `meeting-notes/` | Biên bản họp nội bộ |

## Owner

**COO** quản lý. Mọi thành viên core team đều có thể tạo meeting note.

## Format biên bản họp

```
# Meeting YYYY-MM-DD — Chủ đề
**Người tham gia:** A, B, C
**Thời gian:** HH:MM

## Nội dung thảo luận
- ...

## Quyết định
- ...

## Action items
- [ ] Ai — Làm gì — Deadline
```
