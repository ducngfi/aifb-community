# 📂 Solutions — Giải pháp & Matching

> Luồng 6 + 7: Solution Review + Problem-Solution Matching

Folder này quản lý **danh mục giải pháp AI** trong cộng đồng và **log các phiên matching** (đề bài → giải pháp).

## Cấu trúc

| File / Thư mục       | Mô tả                                                 |
| -------------------- | ----------------------------------------------------- |
| `directory.md`       | 📌 **SSOT** — Danh mục giải pháp phân loại theo 5 nhóm |
| `review-criteria.md` | Tiêu chí review giải pháp (cần tạo)                   |
| `golden-list.md`     | Danh sách Vàng — NCC uy tín, admin đề xuất (cần tạo)  |
| `matching/`          | Log các đề bài + kết quả matching                     |

## 5 nhóm giải pháp (Taxonomy)

1. **AI Agent & Orchestration Platform**
2. **Process Automation & Integration**
3. **Marketing, Content & Sales Automation**
4. **Consulting & AI Strategy**
5. **Vertical Solutions** (by industry)

## Matching Flow

```
Doanh nghiệp đăng đề bài
        ↓
Admin tạo MATCH-XXX_TenDeBai.md trong matching/
        ↓
NCC đề xuất giải pháp (ghi nhận trong file)
        ↓
Admin review + cộng đồng bình chọn
        ↓
Giải pháp tốt → cập nhật golden-list.md
```
